# Hands-On Tutorial: Google Colab + GitHub (Tutorial 9)

This repository contains a Google Colab notebook and a dataset used to demonstrate:
- Opening notebooks from GitHub in Colab
- Loading data using GitHub RAW links
- Cloning repositories
- Reproducibility and collaboration


## How to Run the Notebook

1. Open the notebook file (`.ipynb`) in Google Colab.
2. Restart runtime: **Runtime → Restart runtime**.
3. Run all cells: **Runtime → Run all**.
4. The dataset loads from the `data/` folder via a GitHub RAW link, so no manual upload is needed.
